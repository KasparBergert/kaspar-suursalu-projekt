**Functionality**

1. **User registration +** 
    - Create an account (email + password)
    - Log in / log out

2. **User profile +** 
    - Username or display name
    - Simple profile page showing user’s questions

3. **Ask a question **
    - Creating a question

4. **List questions**
    - Page showing all questions (newest first)
    - upvote a question

5. **Answer a question**
    - Input box under question for answers
    - Save to database

6. **View answers**
    - Display all answers for a question on its detail page
    - Show author and timestamp

7. **Basic interaction**
    - Upvote (and optionally downvote) answers
    - Display vote count

8. **Navigation**
    - Home (question list)
    - Ask Question
    - Profile
    - Log in / Log out
